# ai-teacher-helper

给 AI 教学助手使用的技能与规则仓库。这一页教你：**把仓库交给助手 → 安装技能 → 开始使用**。

下面以 [teacher-init](<skills/teacher-init/SKILL.md>) 为例：它会先了解你的教学情况，再为你选定的教学文件夹建立必要的配置和目录。它不是一个已经包含备课、批改、组卷等全部功能的软件。

## 1. 把完整仓库交给 AI 助手

1. 下载本仓库的完整压缩包，保留全部内容，不要只保存这一页说明。
2. 如果你的 AI 工具支持选择本地文件夹，解压后让它打开仓库文件夹；如果它支持上传并读取压缩包，也可以上传完整压缩包。
3. 发给它下一节的安装指令。你不需要自己判断技能该放在哪个目录。

**先确认工具能做什么：** 读取文档、安装技能、创建教学文件是三种不同的能力。只能聊天或查看附件的工具，不一定能替你安装技能或创建文件。

## 2. 复制这段话，让助手安装技能

把仓库交给助手后，直接发送：

> 请安装这个仓库中的 teacher-init 技能。
>
> 先确认你能读取技能和全部配套文件，再判断当前工具是否支持安装、应该安装到哪里；不清楚时不要猜目录。
> 支持安装的话，请先告诉我目标位置，按当前工具支持的方式安装，保留完整技能目录。已有同名内容先问我，不要覆盖。
> 这一步只安装，不初始化教学工作区，不移动我的教学资料，也不要顺带安装其他内容。
> 完成后告诉我：安装位置、具体调用方式，以及是否已验证当前工具能识别它。缺少权限或不支持安装时，请如实说明，不要把“读过文档”当成“安装成功”。

### 怎么判断这一步是否完成？

| 助手报告的结果 | 实际意味着什么 |
|---|---|
| 已阅读技能说明 | 只是理解了内容，不代表已安装 |
| 已复制到目标位置，识别未验证 | 文件已保存，但还不能保证工具能调用 |
| 已按工具要求安装，并提供技能列表等识别依据及调用方法 | 才算完成了安装与识别验证 |

验证应使用技能列表等只读检查，**不要为了测试安装就开始创建教学目录**。无法验证时保留“未验证”状态即可，不假装成功。

## 3. 第一次使用：初始化你的教学文件夹

安装完成后，**另外选择你准备存放教学资料的文件夹**，或把它的位置告诉助手。
仓库文件夹存放技能，教学文件夹存放你的资料，不能让助手默认把两者当作同一个地方。

如果工具要求先点选技能或输入专用指令，请按上一步确认的调用方式操作。
然后发送下面的示例，把第二段的教学情况换成自己的；不确定的地方写“待定”：

> 请用 teacher-init 初始化我指定的教学文件夹。先和我确认目标位置，不要在能力仓库或技能安装目录里创建教学目录。
>
> 我教初二数学，只任课、不兼班主任。教材版本待定，希望回复简洁，输出以 Word 为主。
>
> 只问还缺少的教学信息，每次不超过四个问题。先列出准备创建或更新的内容，等我确认后再动手。
> 这次只保存教学设定、建立必要目录，不读取真实学生名单或成绩，不移动、删除或直接覆盖已有文件。

### 接下来你会看到什么？

1. **助手补问缺少的信息**：例如教材、教学进度、输出偏好。没有答案可以说“待定”。
2. **助手给出创建方案**：告诉你要在哪个文件夹里新建什么、更新什么。你可以说“这个目录不需要”，再确认执行。
3. **确认后才创建文件**：你会得到教学设定、选定的目录和用途说明，而不是一批预先填好的教案、试卷或学生资料。
4. **助手报告实际结果**：哪些已保存、哪些未完成、以后是否自动读取已经验证。保存成功不代表新会话一定自动生效。

不需要提供学生姓名、成绩或联系方式。文件保存在本地，也不代表云端 AI 读取它时数据不会传到外部服务。

## 4. 以后调整设定，直接这样说

改输出偏好：

> 请用 teacher-init 把我的输出偏好改为 Markdown，其他设定和文件保持不动。先给我看改动再保存。

换学期：

> 请用 teacher-init 更新本学期的教学设定，只问发生变化的部分，不重新创建已有目录。未知的周次和进度先写待定。

这些是更新教学工作区的用法。是否具备其他教学技能，请看 [技能目录](<skills/README.md>)，不要把初始化完成当作所有教学能力都已安装。

## 遇到问题怎么办？

| 遇到的情况 | 下一步 |
|---|---|
| 助手找不到仓库或配套文件 | 请它说明缺少哪个文件；重新选择完整仓库或上传工具能读取的完整材料。原因也可能是权限或压缩包读取能力，不一定是位置写错 |
| 工具不支持安装技能，但能读写文件 | 可以明确要求它“读取这个仓库中 teacher-init 的完整说明和所需配套材料，按说明完成本次初始化”。这属于本次会话使用，不是永久安装 |
| 没有创建或修改文件的权限 | 先保留方案，不算初始化完成；确认目标位置和工具权限后再继续，不必安装脚本运行时 |
| 新会话不知道这个技能 | 重新提供技能位置，或核对当前工具的安装与启用要求。上一次对话读过说明，不等于这一次已经加载 |
