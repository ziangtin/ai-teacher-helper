# 访谈题库

这些是按需选用的问题，不是每次都要问完的表单。**每次最多 4 问，不固定总批次**；
可使用提问功能，也可普通对话，不要求特定工具。

- 已确认的工作区档案与老师本次明确说明优先；二者冲突时问清变化，不从教学资料内容猜设定。
- 未知事实填写“待定”。语气、格式等可以给推荐选项，但未经确认不写成老师的偏好。
- 不索取名单、真实成绩、学生联系方式或个案；初始化只需要教学设定。
- 档案与偏好值统一写进入口的 `profile` 块，人设写入 `persona` 块，关键边界写入 `rules` 块。
  规则模块只说明如何使用这些设定，不再存一份副本。

## A · 身份与角色

| # | 问题 | 可选回答 | 用途 |
|---|---|---|---|
| A1 | 教哪个学段？ | 小学 / 初中 / 高中 / 职校 / 高校 / 成人教育 / 待定 | 目录与教学表述 |
| A2 | 教哪些学科？ | 单科或多科，由老师说明；未知写待定 | 需要哪些教学分区 |
| A3 | 用什么教材或课程材料？ | 版本与册次；没有统一教材也可说明；未知写待定 | 进度与命名依据 |
| A4 | 是否兼任班主任或教研行政？ | 仅任课 / 班主任兼任课 / 任课兼教研行政 / 待定 | 目录裁剪，不默认全建 |

## B · 班级与节奏（按需补充）

| # | 问题 | 可选回答 | 用途 |
|---|---|---|---|
| B1 | 带几个班、每班大约多少人？ | 可用“班级 A”等代号，不需要学生名单 | 档案中的教学规模 |
| B2 | 当前学期、周次和教学进度？ | 老师给出已知部分，其他写待定 | 后续教学计划 |
| B3 | 考试和批改通常怎样安排？ | 单元测 / 阶段测验 / 期中 / 期末等 | 教学节奏 |

## C · 使用偏好

| # | 问题 | 可选回答 | 写入与使用 |
|---|---|---|---|
| C1 | 希望怎么称呼你？ | “老师”或老师指定的称呼 | `profile`；`01-身份与偏好.md` 指向入口读取 |
| C2 | 希望回复是什么语气？ | 简洁直给（建议）/ 温和鼓励 / 严肃简练 | `persona`；不重复记录到其他文件 |
| C3 | 偏好哪种评语形式？ | 要点式 / 鼓励式 / 家长视角 / 暂不需要 | `profile`；`04-产出规范.md` 按该偏好组织 |
| C4 | 希望交付什么格式？ | Word / Markdown / 课件等，可待定 | `profile`；`01-身份与偏好.md` 指向入口读取 |

记录格式偏好不代表当前工具一定能生成该格式；实际交付前再确认能力，不要求老师安装运行时。

## D · 校内要求（有需要再问）

> 有哪些学校规定或特别不能做的事，需要我遵守？

默认边界直接说明，不把是否保护隐私当作可随意关闭的选项：
- 初始化不读取真实学生资料，不自动发送消息、公布成绩或移动旧文件。
- 覆盖、删除、重命名、移动或对外发送，都需单独确认具体范围。
- 本地保存不等于本地处理；云端模型读取文件可能向外部服务传输内容。
  未确认处理环境与授权前仅使用匿名资料；初始化无需为此收集学生原始数据。

## 追问与分支

- **多学科**：建议在教学分区下按学科细分，先确认；未确定学科时不要猜目录名。
- **职校、高校或成人教育**：按实际课程改用“教学大纲 / 课程材料”“阶段测验”等表述。
- **学校有统一模板**：只在需要时请老师提供空白或已脱敏的模板；保留原版，不主动索取已填学生资料。
- **仅任课**：可省略学生与班级分区；需要家校沟通时，再确认是否在作业与成绩分区增加对应目录。
- **角色待定**：只建议收件箱、备课等最小目录，等老师确认，不默认按班主任全建。
- **周次或进度未知**：写“待定”，不填“开学第一周”或猜测教材章节。
- **更新模式**：只问发生变化的项目，不重复访谈。

## 开场示例

> 我先确认你的教学情况，再给你看准备创建的文件夹和说明，得到你确认后才动手。
> 你教哪个学段、哪些学科？用什么教材？是否兼任班主任或教研行政？
> 不确定的可以说“待定”，不需要提供学生名单或成绩。
