# 规则与辅助目录模板

这里存放规则细则与目录说明。档案、人设、关键边界只维护在选定的工作区入口中，
这些目录不承担另一份配置原件，也不保证被当前工具自动加载。

```text
<工作区>/.agents/
├─ rules/
│  ├─ README.md
│  ├─ 01-身份与偏好.md
│  ├─ 02-目录与命名.md
│  ├─ 03-隐私与边界.md
│  ├─ 04-产出规范.md
│  └─ 05-常见任务.md
├─ skills/
│  └─ README.md
└─ mcp/
   └─ README.md
```

所有文件按确认范围创建。已有文件先读，拟更新时展示差异并确认；未确认的原样保留。
模板中的路径占位符须替换为从生成文件所在目录出发的真实相对路径。

## 1. 规则索引模板

保持简短，每行都带“什么时候读”；只链接已经存在或本次确实创建的模块。

```markdown
# 教学规则索引

当前教学档案与偏好见 [工作区说明](<入口相对路径>)，此处不另存一份。
按任务读取需要的模块，不必整目录通读。

| 模块 | 内容 | 什么时候读 |
|---|---|---|
| [身份与偏好](./01-身份与偏好.md) | 从入口读取设定、处理待定项 | 需要教学档案或输出偏好时 |
| [目录与命名](./02-目录与命名.md) | 目录用途与命名方法 | 新建、重命名或归档文件前 |
| [隐私与边界](./03-隐私与边界.md) | 匿名化、处理环境与确认要求 | 涉及学生资料或对外材料前 |
| [产出规范](./04-产出规范.md) | 内容结构、模板使用与核对 | 生成教学材料时 |
| [常见任务](./05-常见任务.md) | 整理、归档等任务的处理步骤 | 用户明确提出相应任务时 |
```

`<入口相对路径>` 指向实际维护档案的入口；助手负责计算，不要求老师填写。

## 2. 模块内容

每个模块先说明何时使用，再列可执行的细则，不重复保存入口中的档案与人设。

| 模块 | 应写什么 |
|---|---|
| 01 身份与偏好 | 链接入口的 `profile`、`persona`；缺少设定时询问或保留待定，不把偏好值复制过来 |
| 02 目录与命名 | 使用 [目录地图](workspace-skeleton.md)，按老师确认的实际目录裁剪 |
| 03 隐私与边界 | 初始化不读取真实学生资料；后续任务先确认处理环境、授权与匿名化要求，不能把本地存储当成本地处理 |
| 04 产出规范 | 按任务明确结构与检查项；学校空白模板优先，格式与评语偏好从入口读取，不能生成的格式如实说明 |
| 05 常见任务 | 用户明确要求后才开展整理、归档等任务；涉及文件变更先列清单确认，归档示例见 [目录地图](workspace-skeleton.md) |

## 3. 技能与 MCP 的占位说明

```markdown
# 技能目录

用于存放工作区需要的技能，每个技能保留完整目录及配套材料。
本说明和空目录不代表技能已经安装；发现、调用与加载方式以当前工具实际支持为准。
教师档案与人设维护在工作区入口，不在这里另存一份。
```

```markdown
# MCP 目录

用于存放 MCP 配置资料与说明，不会仅因创建目录而接入任何服务。
实际接入需按所用工具的要求另行配置并经用户确认；初始化不安装或启用服务。
```

## 4. 教学目录的简短说明

标题外只需说明三件事：放什么、怎么命名、去哪查规则。
具体模板统一使用 [目录说明模板](workspace-skeleton.md)，
按实际层级计算链接，不能每个目录都写同一个 `../`。

教学子目录不额外创建多个入口文件；普通目录说明是否被读取取决于当前工具和任务，不保证自动加载。
