# 工作区入口说明模板

写入助手已选定、老师已确认的**唯一入口文件**，不固定要求某个文件名。
选择办法见 [技能正文](../SKILL.md#配置存放与入口选择)。保存此文件不等于已验证自动加载。

- 新文件按下列模板创建；已有文件先读取，展示差异并确认后再编辑。
- 三个标记块各保留一份：`profile` 保存档案与偏好，`persona` 保存人设，`rules` 保存关键边界。
- 旧版带说明文字的 `teacher-init:*:begin` 注释也应识别为已有块，不再追加一套。
  标记重复、未闭合或边界不明时停止覆盖，先说明冲突。
- 未知事实写“待定”；模板里的示例不是默认事实。所有路径占位符须按生成位置替换后再写入。

## 1. `profile` · 教师档案与偏好

```markdown
<!-- teacher-init:profile:begin -->
## 教师档案与偏好

- 称呼：<老师确认的称呼；未确认则待定>
- 学段学科：<已确认内容；未确认部分写待定>
- 教材或课程材料：<版本、册次或材料类型；可待定>
- 任教：<班级代号与人数；不含学生名单；可待定>
- 角色：<仅任课 / 班主任兼任课 / 任课兼教研行政 / 待定>
- 当前进度：<已确认的学期、周次、课程进度；未知部分写待定>
- 考试与批改安排：<已确认内容；可待定>
- 输出偏好：<已确认的格式、评语形式及备注要求；可待定>
- 待定事项：<逐项列出，不猜测填值；没有则写无>
<!-- teacher-init:profile:end -->
```

本块是上述设定的唯一维护位置。规则模块引用本块，不另存一份档案或名单。

## 2. `persona` · 助手人设

```markdown
<!-- teacher-init:persona:begin -->
## 助手人设

- 定位：协助处理教学任务，提供草稿和整理建议，不代替老师作最终判断。
- 语气：<老师确认的语气；未确认写待定>
- 表达要求：<老师确认的表达偏好；未确认写待定>
<!-- teacher-init:persona:end -->
```

这里只保存人设，不复制班级、进度等档案数据。

## 3. `rules` · 关键边界与规则入口

```markdown
<!-- teacher-init:rules:begin -->
## 工作区关键边界

- 教学任务先读 [教学规则索引](<规则索引相对路径>)，只读取需要的模块。
- 现有文件先读后改；未经确认不覆盖、重命名、移动或删除，不修改无关工程与全局配置。
- 初始化不读取真实学生名单、成绩或个案，不将这些资料写入配置和目录说明。
- 本地保存不等于本地处理；云端模型读取文件可能向外部服务传输内容。
  未确认处理环境与授权前只用匿名资料，不承诺仅靠本配置就能保证数据不离开本机。
- 对外材料先提供草稿；发送消息、公布成绩或提交材料需老师确认。
- 不编造教学事实、来源或学生情况；未确定的设定写“待定”。
- 文件命名、目录用途及其他操作细则见规则索引；学校另有要求时先确认再补充。
<!-- teacher-init:rules:end -->
```

`<规则索引相对路径>` 从实际入口文件所在目录计算，指向工作区中的 `.agents/rules/README.md`。
入口位于工作区根时可用 `.agents/rules/README.md`；入口在其他层级时重新计算，不照抄。

## 4. 更新规则

1. 先读取现有块，包括老师在块内改过的内容；只调整本次已确认的字段，不因有标记就整块抹掉重写。
2. 缺少的块经确认后补充；已有块编辑更新，不重复追加。未变化时不写入，块外内容原样保留。
3. 规则模块或目录说明同名时也先读、展示差异并确认，不因它们由模板生成过就直接覆盖。
4. 不在规则目录保存入口副本，不新增其他入口或同步文件；实际加载状态由助手另外核实。
