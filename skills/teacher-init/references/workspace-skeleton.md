# 工作区骨架、目录地图与命名规范

## 1. 目录全图

这是候选布局，不是每次都要全建。按老师确认的岗位、需要和已有目录裁剪。
入口由助手根据当前工具选择，是否自动加载须另外验证；不把下列结构当作通用安装机制。

```text
<目标工作区>/
├─ <入口说明文件>         ← 档案 / 人设 / 关键边界的唯一维护位置
├─ .agents/               ← 规则细则与辅助目录
│  ├─ rules/              ← 索引与 01—05 模块，按任务读取
│  ├─ skills/             ← 技能存放位置，不代表技能已经安装
│  └─ mcp/                ← 配置资料，不代表服务已经接入
├─ 00-收件箱/
│  └─ 待确认/
├─ 01-备课/               教材与课标 · 教案 · 课件
├─ 02-题库与试卷/         题库 · 组卷 · 默写背诵
├─ 03-作业与成绩/         作业设计 · 作文批改 · 成绩
├─ 04-学生与班级/         名册 · 个案记录 · 家校沟通
├─ 05-教研成长/           听评课 · 课题论文 · 培训学习
├─ 06-行政杂务/
├─ 10-模板库/             教案模板 · 试卷模板 · 评语模板
├─ 20-智能体/             记忆 · 提示词 · 工作流
└─ 99-归档/
```

已有目录和文件不因这张地图而被迁移或覆盖。教学目录放简短用途说明，不额外生成入口文件。
初始化只建已确认的目录与配置，不读取名册、成绩或个案，也不往这些目录填入真实学生资料。

## 2. 命名规范（写进 `.agents/rules/02-目录与命名.md`）

以下是可确认采用的命名建议。已有学校规范优先，不为统一命名擅自改旧文件名。

```text
<学册>-<单元>-<课序>-<课名>-<类型>
例：7上-2单元-05-<课名>-教案.md
    7上-2单元-05-<课名>-课件.pptx
```

| 段 | 取值 |
|---|---|
| 学册 | 年级与学期，如 `7上`；不适用时按实际课程改用课程代号 |
| 单元 | 如 `2单元` |
| 课序 | 两位数字，如 `05` |
| 课名 | 课文名或课题名 |
| 类型 | 教案 / 课件 / 学案 / 作业 / 试卷 / 答案 / 解析 / 讲稿 / 评语 / 记录 |

其他类别的建议模式：

- 整卷：`卷-<学册>-<范围>-<类型>-<YYYYMMDD>.docx`（答案加 `-答案`，解析加 `-解析`）
- 成绩：`成绩-<班级代号>-<考试名>-<YYYYMM>.xlsx`（整理版另存 `-整理.xlsx`）
- 批改：`批改-<班级代号>-<作文题>-<YYYYMMDD>.md`
- 个案：`个案-<匿名代号>-<YYYYMMDD>.md`
- 通知：`通知-<班级代号>-<事项>-<YYYYMMDD>.md`

用 `-` 分隔，日期按 `YYYYMMDD` 或 `YYYYMM`；新版本另存，不覆盖旧版。
新类型或未知命名字段先确认，不猜测内容。这些是未来产物的示例，初始化不生成对应教学资料。

## 3. 目录地图（写进 `.agents/rules/02-目录与命名.md`）

| 目录 | 放什么 | 关键约束 |
|---|---|---|
| `00-收件箱/` | 未归类资料；`待确认/` 存待判断的文件 | 用户要求整理时才列归位方案，确认后执行，不覆盖同名文件 |
| `01-备课/` | 教材与课标、教案、课件 | 源资料保留原版；教学产物另存，不擅自改学校模板 |
| `02-题库与试卷/` | 题库、组卷、默写背诵 | 不编造题目来源；卷、答案、解析按任务要求分别整理 |
| `03-作业与成绩/` | 作业设计、作文批改、成绩 | 初始化不读真实成绩；后续任务先确认处理环境与授权，默认使用匿名资料，原始表保留 |
| `04-学生与班级/` | 名册、个案记录、家校沟通 | 初始化不读真实资料；本地存储不等于本地处理，不能靠目录约定保证数据不外传；对外内容先出草稿 |
| `05-教研成长/` | 听评课、课题论文、培训学习 | 不编造文献与数据；没有找到出处就明确说明 |
| `06-行政杂务/` | 报表、通知、值班表、填报材料 | 不代签、代报、代发；涉及个人信息先确认处理边界 |
| `10-模板库/` | 教案、试卷、评语模板 | 学校空白或已脱敏模板优先；已有模板不覆盖 |
| `20-智能体/` | 记忆、提示词、工作流 | 不另存教师档案副本；不存学生个人信息或密钥 |
| `99-归档/` | 已确认归档的学期资料 | 已完成的归档只读；新批次另行确认，不改动旧档 |

匿名资料应在获准的环境中准备好，不能先把原始学生资料读入处理方式不明的模型再脱敏。

## 4. 工作目录说明模板

标题外只说明三件事。所有已有说明先读；需要更新时展示差异并确认。

```markdown
# <目录名>

放什么：<一句话>。
命名：<一句话 + 一个例子>。
规范细节见 [目录与命名](<规则文件相对路径>)。
```

`<规则文件相对路径>` 从该说明文件所在目录算到工作区的 `.agents/rules/02-目录与命名.md`。
助手在写入前替换占位符，并检查最终目标；一级、二级目录不能套同一个路径。

| 说明所在目录 | 对应相对路径 |
|---|---|
| `01-备课/` | `../.agents/rules/02-目录与命名.md` |
| `01-备课/教案/` | `../../.agents/rules/02-目录与命名.md` |

其他层级按实际位置计算，不写入机器绝对路径。

## 5. 岗位裁剪

候选目录见 [目录清单](directories.txt)，只创建老师确认需要的部分。

| 岗位 | 建议 |
|---|---|
| 班主任兼任课 | 可建议各教学分区，按实际需要确认，不因角色而直接全建 |
| 仅任课教师 | 可不建学生与班级分区；需要家校沟通目录时再确认位置 |
| 任课兼教研行政 | 优先考虑教研与行政分区，其余按需 |
| 小学低年级 | 组卷、作文批改等子目录按实际教学需要取舍 |
| 角色待定 | 先建议收件箱、备课等最小目录，等待确认 |

## 6. 学期归档流程

这是用户另行要求归档时的参考，不属于默认初始化。

1. 确认要归档的学期与范围，不自动判断学期已结束。
2. 列出旧文件与归档目标的对应清单，包含同名冲突；确认前不移动。
3. 确认后归档到新的学期批次，保留区内结构，不覆盖既有归档；失败时报告已完成与未完成项。
4. 老师要求更新教学设定时，再确认并修改唯一入口的 `profile` 块。未知学期、周次或进度写待定。
5. 已有教学目录骨架保留，不因换学期重建或恢复已裁掉的目录。
