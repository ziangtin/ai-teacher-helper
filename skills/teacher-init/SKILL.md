# 教师工作区初始化向导

带老师确认教学设定，再建立可使用的配置与目录。老师只回答教学问题，技术适配由助手处理。

**安装、复制或查看技能不等于初始化。** 不得因为读到了本文件就启动访谈或创建教学目录；
只有用户明确要求初始化或更新时，才执行下面的流程。

## 产出

| 内容 | 位置 | 用途 |
|---|---|---|
| 教师档案、助手人设、关键边界 | 一份工作区入口说明 | 保存当前教学设定，是这些设定的唯一维护位置 |
| 规则索引与细则 | `.agents/rules/` | 索引写清什么时候读哪个模块，细则按需读取 |
| 技能与 MCP 的占位说明 | `.agents/skills/README.md`、`.agents/mcp/README.md` | 说明目录用途，不代表已经安装技能或接入服务 |
| 教学目录及简短说明 | 老师确认的目标工作区 | 每个教学目录说明放什么、如何命名、去哪查规则 |

`.agents/` 是本技能的整理约定，不代表所有智能体工具都能自动识别。

## 配置存放与入口选择

- **档案、人设、关键边界只维护一份**，存放在工作区入口说明中；规则目录只放索引和执行细则，
  不再复制一套档案或人设。
- 优先沿用目标工作区内已经包含 `teacher-init` 标记块的入口。尚无配置时，由助手根据当前工具
  明确支持的工作区入口选择文件，不让老师判断文件名、复制方式或链接类型。
- 无法确认工具支持哪种入口时，可在创建方案中使用工作区根的 `AGENTS.md` 保存普通配置，
  并明确说明自动加载尚未验证。若发现多份已有配置相互冲突，先说明差异，不自动合并或覆盖。
- 不生成入口副本、不建立软硬链接、不添加同步机制。已有其他工具配置原样保留。
- **是否自动加载，以当前工具实际支持为准。** 不统一假定加载路径、引用方式或上下文预算；
  文件存在、当前对话读过文件，都不等于后续会话会自动加载。

## 向导步骤

### 第 1 步 · 确认请求、目标与能力

1. 确认用户要求的是初始化或设定更新，而不是安装、复制、查看技能。
2. 确认老师要整理的教学文件夹，并展示实际目标位置。目标不清楚时用大白话问清楚，
   不能默认把能力仓库、技能安装目录或当前命令目录当作教学工作区。
3. 检查当前工具是否允许读取和写入该目标。只查看目录结构及必要配置，不读取学生名单、
   真实成绩或个案。没有写入能力或权限时，可给出方案，但须说明尚未创建文件。
4. 按“入口选择”确定唯一维护文件。没有标记块时准备初始化，已有完整标记块时只问变化。
   已有标记重复、未闭合或内容冲突时先说明情况，不猜测覆盖范围。

### 第 2 步 · 只问需要的教学问题

按 [访谈题库](references/interview.md) 提问，每次最多 4 问，不固定总批次。
已提供的信息不重复问；可使用当前工具的提问功能，也可直接用普通对话，不依赖特定工具名。

优先了解学段、学科、教材和角色；班级代号、教学进度、风格与输出偏好按需补充。
未知事实写“待定”，不要补成某个年级、教材版本或“开学第一周”。
可提出语气、格式等偏好建议，但须经老师确认后才记为其设定。

初始化不索取或读取真实学生资料。涉及后续隐私处理时，明确区分本地存储与模型处理：
云端模型读取本地文件也可能把内容发送到外部服务；未确认处理环境与授权前只用匿名资料。

### 第 3 步 · 给出方案，等老师确认

用三五行复述已知设定与待定项，再根据 [目录清单](references/directories.txt) 和
[岗位裁剪说明](references/workspace-skeleton.md#5-岗位裁剪) 提出目录方案。

清单必须列出：目标位置、将新建的目录和文件、拟更新的已有内容、保持不动的内容。
已有文件需要改动时展示差异；确认本次范围后才写入。没有确认的操作不夹带执行。
角色不明时先给最小方案，不默认全建。移动旧资料不属于默认初始化。

### 第 4 步 · 按确认范围创建或更新

1. 使用 [配置块模板](references/agents-md-blocks.md) 写入选定入口。
   新文件按模板创建；已有文件先读，已有标记块只更新确认的内容，缺少的块经确认后补充。
   不重复追加标记块，不改老师的其他内容。
2. 按 [规则目录模板](references/agents-dir.md) 建立已确认的规则索引与模块。
   档案和人设仍只保存在入口；索引链接必须指向实际存在的模块。
3. 创建已确认的教学目录和简短说明，已有目录跳过。规则模块、目录说明等所有已有文件
   都先读后改；同名文件不能直接覆盖，没有确认的差异保留并报告。
4. 按生成文件的实际位置计算相对链接，填入真实入口和规则路径；不得把一级目录的路径
   原样套到二级目录。写入前再次检查目标是否变化，出现新冲突就停下说明。
5. 任一步失败都记录已完成和未完成的部分，不为“重试”擅自清空或删除已有成果。

### 第 5 步 · 核对结果并交代清楚

- 读回本次文件，核对设定、待定项、标记块数量与引用目标；检查未确认的内容是否保持原样。
- 分开报告：**配置已保存**（实际文件位置）、**自动加载状态**（已验证／未验证／不支持）、
  **尚未完成**（具体原因及剩余项）。只有有实际加载证据时才能说已验证，不能用当前对话主动读过来代替。
- 只有已确认范围内的创建和更新全部成功，才说“初始化完成”；未验证自动加载时同时说明这一限制。
- 给出与本技能相符的后续说法，例如“补充本学期进度”“只更新输出偏好”“说明这些文件夹的用途”。
  不把阅读技能、保存配置或创建空目录说成“所有教学技能已安装”。

## 更新与边界

- 更新前读取唯一维护入口，只问变化项；展示差异并确认后编辑对应内容。未变化时不写入，
  不重复建文件、追加标记块或恢复老师已裁掉的目录。
- 只写入老师已确认且当前工具有权限操作的目标工作区。不修改技能来源仓库、全局配置或其他工程。
- 不默认移动、重命名或删除旧资料。用户另行提出整理要求时，再给清单确认。
- 默认不读取真实学生名单、成绩和个案；不把隐私资料写进入口配置或目录说明。
- 不要求老师安装运行时或插件。工具不能读写时如实说明限制，不声称“任何环境都能完成”。
- 教学子目录只放简短用途说明，不额外铺设多个入口文件。

## 执行细节

**目录与资源**：用当前可用的文件工具或命令，按确认后的清单建目录，已有目录跳过。
不需要本技能自带脚本。配套材料相对于本技能目录定位，不能相对于目标工作区猜路径。

**编码**：文本按 UTF-8 读写。Windows PowerShell 5.1 在未指定编码且文件无 BOM 时，
`Get-Content` 默认使用系统 ANSI 代码页；`Set-Content` 对新建或空文件默认使用系统代码页，
而 `Out-File` 默认使用 UTF-16LE。PowerShell 7 默认使用 UTF-8（无 BOM）。
若使用命令行读写，应明确指定 UTF-8；乱码来自读写编码不匹配，不是使用 ANSI 就必然出错。
